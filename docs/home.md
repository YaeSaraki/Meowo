# Home 使用说明

`/home` 或 `/homes` 打开 **TabooLib Chest UI**。每个玩家默认可设置 10 个家，可通过容量权限扩展，只能管理自己的家。

## 使用
- 空位：在当前位置设置家，确认收费后保存。
- 已有家：左键确认回家，右键打开编辑。
- 编辑页：免费修改名称、颜色、导航可见性、定位栏图标、菜单物品图标；迁址和删除另有确认页。
- 改名：从 GUI 发起后在聊天输入，文字仅被该操作接收，不向其他玩家广播；`cancel` 取消，60 秒失效。
- `/sethome [编号或名称]`：设置/迁址；`/home <编号或不含空格的名称>`：确认回家。
- `/home edit <编号>`、`/delhome <编号>`：编辑或确认删除。
- `/home nav <编号>`：选择 BossBar 辅助导航；`/home nav off`：关闭辅助导航。
- `/home cancel`：取消回家倒计时并返还预扣费用。
- `/home color <编号> <色名或#RRGGBB>`：免费设置 RGB 颜色。
- `/home show <编号> <on|off>`、`/home icon <编号> <default|bowtie>`：免费修改定位栏显示。
- `/home icon <编号> <物品名>`：免费修改这个家在总览里画成的图标（`white_bed`、`bell` 等 16 种）。

## 收费
| 操作 | 默认金额 |
| --- | --- |
| 设置家 / 修改位置 | 确认操作时的钱包余额 × 5%，最低 100，最高 2333 |
| 同世界回家 | `sqrt((当前位置X-家X)^2+(当前位置Z-家Z)^2)/10`，最低 100，最高 2333 |
| 跨世界回家 | 2333，可配置费用或禁止 |
| 名称 / 颜色 / 图标 / 导航 / 删除 | 免费 |

单位沿用 economy 的 Meo / ฅ 配置，金额向上取两位小数。税款进入 **eco**，继续通过既有每日登录补助发放。设置税预览是估算，结算依据确认时余额；回家依据确认时当前位置。删除不会退回历史已结算税。

回家先异步加载已生成的目标区块并检查落点，再预扣和等待 3 秒。允许转动视角；位移超过 1/16 方块容差会取消并退还预扣，容差固定比较出发位置，缓慢走动也不能绕过。区块不可用、落点危险、外部插件阻止传送、离线或模块关闭均不会结算失败传送。与 TPA 共用行程互斥、白色旋转符文串、群系配色的旋转六芒星、反胃/黑暗 4 秒和缓慢 3 秒。

## 导航与辨别
- 原版定位栏显示在经验条区域，只向所有者发送其当前世界里已启用导航的家；不创建公共实体，不改真实经验、等级或世界规则。
- 原版内置 `default`（随距离变化的圆点）和 `bowtie`（蝴蝶结）；更多定位栏图标需资源包。遵循原版视角范围、距离尺寸、高低箭头和获得经验时暂显经验条的行为。
- GUI 有 16 种颜色、16 种物品图标，支持额外 RGB 颜色；同时显示编号、名称、世界、坐标、水平距离和高度差。
- 选中辅助导航后，BossBar 显示方向刻度、名称、相对方向、距离和高低差。另一世界显示世界名。
- 定位栏需要 PacketEvents 2.14.0 与支持 waypoint 的客户端（1.21.6+）；未安装或客户端不支持时仍可使用 GUI 和BossBar 辅助导航。

## 配置与数据
`config.yml` 的 `contexts.home` 控制启用；`home` 段可修改数量（1–1000）、比例、最低/最高金额、距离除数、跨世界策略、倒计时、粒子、定位栏和 BossBar。修改后 `/meowo reload` 生效，原有数据保留。降低数量上限仍展示旧家，只限制新建。

家保存在 `plugins/Meowo/home/homes.db`，钱包/eco/收费账本仍在 `plugins/Meowo/economy/wallets.db`。备份时建议正常停服后一起保存这两个数据库。付费位置修改保留旧记录及预扣 ticket；重启按账本提交/退款状态完成保存或回滚。

所有页面使用 TabooLib 标准 Chest。固定 TabooLib 版本对 Paper 26.2 的 NMS 支持不足，本项目排除 BukkitUI 套件附带的 `bukkit-nms`，保留标准 UI 与默认版本保护；不使用虚拟背包、Anvil 或 raw-title 功能。

## 总菜单与容量权限

Shift + F（潜行时交换主副手键）或 `/menu` 打开总菜单，家园入口进入 menu 模块绘制的 28 格分页总览；`/menu homes 2` 直接打开第二页。超过一页会自动生成更多页面，使用左右箭头翻页。

默认容量仍为配置的 `home.limit`（10）。赋予 `meowo.home.limit.20`、`meowo.home.limit.50` 等权限可覆盖容量，取已授权的最高数字，支持 1–1000；降低容量保留旧家并允许使用和编辑。SQLite 自动迁移旧 10 格限制并保留待结算记录。

新家默认可见，定位条图标为蝴蝶结。辅助导航使用 `home.bossbar` 配置，旧 `home.actionbar` 配置作为兼容回退；`/home nav off` 即时关闭，详情页导航按钮再次点击也可关闭。见 [UI 绘制规范](ui-style.md)。
