# meowo-shop · 喵达 ModaCat 商店

把矿石换成钱。默认**所有玩家**都有权限（`meowo.shop`），拿到矿就能卖。

## 玩家看到的行为

| 操作 | 结果 |
|---|---|
| `/sell` | 卖掉背包里**所有**能回收的矿石——会先弹一次确认页 |
| `/sell all <矿物>` | 只卖这一种（价目表里**左键**那一格） |
| `/sell hand` | 只卖主手那一叠（价目表里**右键**那一格） |
| `/sell gui` | 打开价目表（主菜单里那一格也是它） |
| 背包里没有可回收的东西 | 一句话告诉你，然后什么都不动 |

卖完会给一份明细：每种矿石 × 数量 = 多少钱，最后一行是合计和当前余额。

## 价格

单价是**一个**矿石的价，深层矿与地表同价。表在 `config.yml` 的 `shop.prices`，
随插件附带默认值；写错材质名会被忽略（不会让 `/meowo reload` 失败），
新增一种矿物只要写一行材质名，价格就生效。

| 矿石 | 单价 |
|---|---|
| 煤矿（含深层） | 3 |
| 铁矿、下界石英矿（含深层） | 5 |
| 铜矿（含深层） | 15 |
| 红石矿（含深层） | 20 |
| 金矿（含深层） | 50 |
| 钻石矿（含深层） | 100 |
| 青金石矿（含深层） | 120 |
| 绿宝石矿（含深层） | 1000 |

## 三个刻意的决定

**卖光要问一次。** `/sell` 没有参数，意思只能是"背包里所有能卖的东西"，
而背包里常常还有别的东西。明确点了某一格则不问——那一格写的就是"这一种全卖"，
玩家已经说清楚了。

**先取货，再付款；付款失败就把货原样还回去。** 少付一次比多付一次轻：
物品会回到玩家手里，而钱不会自己长回来。取货按槽位逐个扣，部分堆叠剩下的部分会留下，
绝不会把别的物品当矿石卖掉。

**表里没有的矿物不收，也不值零。** 它根本不会进报价，也不会被从背包里拿走。

## 代码在哪

- `ShopSettings` — 价格表与随附默认值。
- `ShopQuote` / `ShopMath` — 报价算法，不碰 Bukkit，所以能用纯数据钉住。
- `ShopContext` — 命令、价目表界面、确认页与钱包结算。

算法本身在 `ShopMathTest` 里钉住，端到端行为在 `core` 的 `ShopIntegrationTest` 里。
