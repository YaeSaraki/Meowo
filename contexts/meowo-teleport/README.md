# Teleport

`/tpa 玩家` 请求传送到对方，`/tpaccept [玩家]` 接受，`/tpdeny [玩家]` 拒绝，`/tpacancel` 取消。也可使用 `/meowo tpa 玩家|accept|deny|cancel`。权限 `meowo.teleport` 默认开放。请求消息里的 `[接受]` / `[拒绝]` 可直接点击，等价于手动输入。

接受流程严格分四步：**对方同意 → 才开始扣费（进托管）→ 开始传送特效并等待 `teleport.countdown-seconds`（默认 3 秒）→ 真正传送**。等待期内 `/tpacancel` 或申请者实际移动（包括跳跃、同一方块内走动）会取消，费用全额退回实际付款方；转头不取消。扣费前、传送后都由托管记录兜底，进程崩溃不会双重扣款。

一个玩家只能发出一个待处理请求；同一目标最多积压 10 个请求，默认 60 秒过期。有多个请求时必须指定请求者，不能误接受其他人。断线、模块停用会清理请求与粒子任务。

Teleport 只依赖 `api` 中的 `SettlementAPI`，不导入 economy 实现。请求者即被传送者，默认负责付费。接受时在经济工作线程预扣费用，再回主线程检查双方在线且存活；传送到在线目标已加载的区块，避免同步生成远处区块。成功后提交税收，取消、事件拦截、断线、主动取消及异常均退款。

若请求者余额不足，**不传送**，改为通知接受者：接受者可再次同意，此时费用改为从接受者钱包预扣（垫付）。垫付只允许一次，且不延长请求有效期；接受者也付不起时直接失败，不会循环索要。垫付合计为申请者的传送税 + 该税额 1% 的支付税，均在失败时退还垫付者。

预扣成功、倒计时开始时，生成贴身的白色符文串：六枚细小符文由淡色光线连接，距身体中心约 0.52 格，约 1.75 秒绕身一圈，每 2 tick 更新。转动视角不会取消；实际移动仍取消并退款，取消、退出或模块关闭时停止特效。

成功抵达后，脚下出现直径约 1.72 格的六芒星阵，由细外环与两个交错三角形组成，约 3 秒内缓慢旋转 31°，末段光点逐渐变细。法阵固定在真实落点，并取该处群系配色：森林鼠尾草绿、海洋雾蓝、冰雪银蓝、沙漠香槟金、沼泽灰青、樱花浅玫瑰、蘑菇岛薰衣草紫；下界灰红/灰金/浅玉色/灰紫，末地浅紫。外环使用同色系的淡色，避免高饱和色与粗线条。两种特效均可通过 `teleport.particles` 关闭。

等待开始时，被传送者获得反胃 I、黑暗 I 和缓慢 I。反胃/黑暗持续 **配置的等待时长 + 1 秒**（默认 4 秒），覆盖整个 3 秒倒计时和抵达后 1 秒；缓慢只持续倒计时。黑暗替代此前的失明。默认不显示额外药水粒子或图标；已有更长或无限效果保留，较短的已有效果只延长、不降级，并保留显示设置。取消时自然到期，避免误清除其他插件给予的效果。


插件关闭时先停止 teleport，向同一经济队列提交退款，再让 economy 排空队列。SQLite 暂存记录支持重复结算与启动恢复。Minecraft 世界移动与 SQLite 无法组成同一原子事务；如果进程恰好在世界移动成功后、税收提交前崩溃，重启退款，可能产生一次免费传送，不会重复扣款。

配置：`contexts.teleport`、`teleport.request-seconds`、`teleport.countdown-seconds`、`teleport.particles`；计费与补助由 economy 配置。economy 关闭时 teleport 自动停用。


位置检测忽略纯视角变化，并容忍起点周围 1/16 格以内的微小坐标修正，避免转动准星时误取消。每次都相对倒计时开始时的位置检查，累计慢走超过此范围仍会取消并退款；倒计时结束前使用同一规则再次检查。
