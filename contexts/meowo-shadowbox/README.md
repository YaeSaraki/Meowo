# meowo-shadowbox · 潜影盒

自带物品栏的**潜影盒**。默认**所有玩家**都有权限，拿到就能用。

## 玩家看到的行为

| 操作 | 结果 |
|---|---|
| 物品栏里 **Shift + 右键**潜影盒 | 打开它的盒子界面 |
| 手拿着潜影盒 **Shift + 右键** | 打开它的盒子界面（不会把方块放下去） |
| `/shadowbox` | 打开主手上的潜影盒 |
| `/shadowbox give <玩家>` | 发一个潜影盒（OP） |

两个键位任选其一，效果完全一样。

## 它到底是什么

没有资源包，所以潜影盒是**一个自带方块实体背包的原版方块物品**。
**盒子里的东西存在物品自己身上**（`BlockStateMeta` 的方块实体 NBT），和原版潜影贝盒完全一样。

**任何带「窗口大小背包」的方块物品都能当潜影盒开**，不要求是本插件发的：
任何颜色的潜影贝盒、箱子、木桶、末影箱……玩家自己捡到的也能用，
插件被卸载后它依然是正常的潜影贝盒。`/shadowbox give` 发出的那个额外带
`meowo:shadowbox` 标记、一个唯一 id、专属名称和说明，所以看起来更清楚、回写也更稳。

判定只看**物品自身的能力**（方块状态带背包、且容量是 1~6 行），
不看我们的标记。漏斗（5 格）、熔炉（3 格）摆不成窗口，所以不算盒子。

这样做的理由见 [docs/minimax/14-shadowbox.md](../../../docs/minimax/14-shadowbox.md)：
内容随物品走、崩服最多丢「刚放进去还没结算的那部分」、原版客户端自己会按 NBT 拆栈防复制，
而且**不需要数据库、不需要异步、不需要孤儿数据清理**。

## 没有 id 的盒子会被「认领」

关闭界面时按盒子 id 找回那一个潜影盒。玩家自己捡来的盒子一开始没有 id，
所以**第一次打开时就给它补一个**，并把补过的物品放回原来的位置——
之后按 id 找就永远找得到，标记在游戏里完全不可见。

## 硬性保证：任何路径都不丢物品，也**绝不**多给

关闭界面时按盒子 ID 在玩家背包里找回那一个潜影盒，把内容写回去：

- 正常关闭 / 退出 / 死亡 / 模块 reload —— 盒子在背包里，内容原样写回（死亡时盒子跟着一起掉落）
- 盒子被别的插件挪走了 —— **把内容直接还给玩家**并打一条 WARN，绝不凭空销毁
- 内容写不进去（比如物品 NBT 过大撑爆物品上限）—— 退回给玩家并打日志，**不吞**

打开界面期间，盒子本身是**锁住**的：点击、丢弃、拖拽、Shift 移动、与副手交换都会被取消，
所以不会出现「内容写不回某个盒子」导致复制的情况。

**关闭窗口时会把窗口清空。** 这一步是防刷的必需项：这种界面背后没有方块实体，
原版在关窗时会**自己**把内容还给玩家；只存不清等于一份进盒子、一份进背包。
详见 [docs/minimax/14-shadowbox.md §4.1](../../../docs/minimax/14-shadowbox.md)。

**一叠盒子（数量大于 1）会被拒绝打开**，提示先拆开。整叠是同一个物品对象，
共享一个 id 和一份 NBT，写回后原版拆栈会让每只都带上同一份内容。

## 配置

```yaml
contexts:
  shadowbox: true          # 关掉就撤掉监听器和命令
shadowbox:
  material: SHULKER_BOX   # 潜影盒长什么样；必须是带方块实体背包的容器方块
  give-permission: true   # /shadowbox give 是否需要 meowo.shadowbox.give
```

`material` 写错（不是物品、或不带容器方块实体）会被**拒绝**并沿用 `SHULKER_BOX`，
不会让 `/meowo reload` 崩掉——`require` 只挡真正的类型错误。

## 谁能做什么

| | 打开自己手上的盒子（两个键位 + `/shadowbox`） | `/shadowbox give <玩家>` |
|---|---|---|
| 普通玩家 | ✅ 所有人 | ❌ 默认不行 |
| OP | ✅ | ✅ `meowo.shadowbox.give`（`default: op`） |

**`give` 是这里唯一会凭空造出物品的动作，所以默认关着。** 权限不够时它在三处都不出现：
Tab 补全、用法提示文本、玩家名补全——三处共用同一个 `mayGive()` 判定。

确实想让所有人互发盒子，把 `give-permission` 设成 `false` 即可。
