# Menu

总菜单。MenuSettings 描述配置里来的每一格（内置三格也是配置，只是有默认值）；MenuContext 负责用例编排、Bukkit 适配和资源管理。只经 EconomyAPI 查询余额，经 BalanceChanged 刷新已打开的菜单。

每一格由 `config.yml` 的 `menu.items.<id>` 决定。`action: command` 的格子以**点击者本人**身份执行 `command`——这条命令不需要在本插件里注册过，所以任何已有指令都能绑上来，而它自己的权限检查照常生效，格子不会变成绕过权限的后门。`name` / `lore` 是服主自己写的文本（支持 `&` 和 `§`），`{player}` 替换成玩家名；内置格子的 `name` 留空时用语言文件，因此仍然随玩家客户端语言切换。`permission` 填了就只对有权限的玩家显示。

取消本菜单中的点击和拖动；每次点击都被推到下一 tick 的主线程，所以执行命令时不会跨线程碰玩家。点击命令格后菜单保持打开：会自己开界面的命令直接把这一格换掉，不开界面的命令则原地不动。异步回调回到主线程，检查菜单仍是当前实例。关闭 context / 切语言 / 改菜单配置时关闭库存并退订，不缓存 Player 对象。无 economy 时显示服务不可用。

家园界面（`openHomes`）是分页的、每一格的数据都来自 HomeMenuAPI，因此仍由代码编排，不在这套配置里。
