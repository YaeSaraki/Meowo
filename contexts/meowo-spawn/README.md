# Spawn

`/spawn` 传送玩家回世界出生点，`/setspawn` 把出生点移到管理员脚下。免费——回城不收费。

权限：`meowo.spawn` 默认所有人，`meowo.spawn.set` 默认 OP。命令别名走 `/meowo spawn`、`/meowo setspawn`。

## 防滥用保护

对齐 EssentialsX 的事实标准，全部可在 `config.yml` 的 `spawn:` 段调整或关闭：

| 保护 | 默认 | 行为 |
|---|---|---|
| 预热 | 3 秒 | 期间移动到**别的方块**或受到伤害即取消；转头和方块内小幅移动**不会**取消 |
| 冷却 | 5 秒 | 在**接受请求时**计费，所以「取消后立刻重来」绕不过去 |
| 安全落点 | 开启 | 出生点不安全时上下搜索最近的可站立位置 |
| 传送后无敌 | 4 秒 | 恢复玩家**原本**的无敌状态，不会把创造模式玩家改成可被伤害 |
| 方块中心对齐 | 开启 | 对齐到目标方块中心 |

## 安全落点扫描的四条硬约束

实现在 `platform/SafeDestination.kt`，是本项目里最容易写错的一段：

1. **绝不生成区块。** 目标区块未加载时直接失败并告知玩家，而不是同步生成拖垮 tick。
   即使 `safety: false` 也保留这道守卫。
2. **上下都有界。** 最多各扫描 `safe-search-range` 格，虚空世界和全空气列都会正常终止。
3. **检查整个身体。** 脚和头都必须在非实心方块里，脚下必须是实心且非危险方块。
   只找「从上面第一个实心块」会把玩家丢进岩浆或卡进 1×1 竖井。
4. **优先使用原点。** 先试出生点本身，再依次向上下就近搜索，符合玩家对「传送到最近的安全方块」的理解，
   不会把人丢到房顶上。

## 状态清理

预热、冷却、无敌三类状态全部只存在 context 内存里，并在三个时机显式清理：

- `PlayerQuitEvent` —— 玩家离线
- `close()` —— context 停用或重载；**会立即恢复无敌状态**，不会把人留在无敌里
- 重复发起 —— 新请求前先取消旧的预热

## 关闭顺序

spawn 不依赖任何其他 context（免费、不碰经济），因此启用/停用顺序对它没有约束。
详见 [docs/minimax/02-运行时与生命周期.md](../../../docs/minimax/02-运行时与生命周期.md)。

## 已知限制

- `spawn.world` 为空时使用**玩家当前所在世界**的出生点。多世界服想统一回大厅，需要显式填写世界名。
- 只在世界出生点层面生效。EssentialsXSpawn 的「首次进服出生点」与「死亡后强制回出生点」
  （`spawn-on-join` / `respawn-at-spawn`）**未实现**；`World.setSpawnLocation` 会成为无床玩家的自然回落点。
- `/home`、`/back` 属于 EssentialsX 的 home/warp 功能，**需要玩家持久化数据**，本项目未做。
