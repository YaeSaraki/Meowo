# meowo-invsee

`/meowo invsee`（根级 `/invsee`）—— 管理员打开另一位玩家的背包，查看、取走或交换物品。
纯物品功能：不收费、不传送、不落盘，只在两人之间搬物品。

## 命令与权限

| 命令 | 权限 | 默认 | 行为 |
|---|---|---|---|
| `/meowo invsee <玩家>` / `/invsee <玩家>` | `meowo.admin.invsee` | OP | 打开该玩家的背包窗口 |
| `/invsee` 无参数 | 同上 | — | 显示用法 |
| `/invsee 自己` | 同上 | — | 拒绝（自己的背包本来就开着） |
| `/invsee <不在线>` | 同上 | — | 报「无法解析该玩家」 |

`meowo.admin.invsee` 同时是 `meowo.admin` 的子节点，所以可以只把「查看背包」这一件事
交给版主，不连带其它管理权限。

context id 为 `invsee`，可用 `contexts.invsee: false` 关闭。

### 窗口里怎么操作

| 操作 | 结果 |
|---|---|
| 左键 / 右键点击一叠 | 整叠取到管理员手上（左右键行为一致） |
| Shift + 左键 | 直接进管理员自己的背包 |
| 在自己背包那半边普通点击 | 原版规则 |
| 在自己背包那半边 Shift + 左键 | 变成一次真实给予；对方满仓时溢出掉在对方脚下 |
| Q / 数字键 / 双击 / 中键 | 拒绝，并说明该用哪几种键 |
| 拖拽 | 拒绝，并提示先拿起再点 |

窗口共 54 格：前三行是对方的仓储、第四行是快捷栏，然后是头盔 / 胸甲 / 护腿 / 靴子 / 副手，
剩下 13 格是填充玻璃板。注意护甲这一行在袋子里是**从脚往上**存的（36 靴 … 39 头盔），
窗口要从头往下读，所以映射是倒着走的。

## 配置

```yaml
contexts:
  invsee: true      # 关闭后 /invsee 与窗口一起消失
invsee:
  audit: true       # 每一次拿取 / 给予写一行服务器日志（谁、从谁那里、多少个什么）
```

**只有 `audit` 一个开关**，因为其余都是**物品守恒**规则：窗��里的每一次点击都必须让
「管理员手上 + 管理员背包 + 对方背包」的物品总数不变。提供关掉它的开关，等于提供
一个复制物品的开关。

## 关键实现约束

**窗口只是镜像，每一次搬运都立刻写进对方的真实背包。**

`Bukkit#createInventory` 造出来的窗口不是容器，而 `InventoryClickEvent` 在原版动手**之前**
触发——原版不管怎么点，改的都是那个镜像，对方的 `PlayerInventory` 一下都不会动。
放任原版跑的后果是：管理员手上凭空多一份，对方的原件原地不动，**每点一次复制一次**。

所以本 context 每次点击都自己执行搬运然后 `isCancelled = true`，并且**没有"关窗时结算"这一步**：
东西在点下去的那一瞬间就已经在正确的人身上了。管理员被踢、context 被 reload、对方中途下线，
都不会留下一叠物品停在窗口里等一条可能永远不走的退出路径。

其余几条：

- **槽位映射写在 `InvseeLayout` 一张表里**，两个方向都从它派生。`PlayerInventory` 的快捷栏在
  0–8、仓储在 9–35，而窗口是按行读的——搞反了肉眼看不出来，却会拿错东西。
- **只有左键 / 右键 / Shift 被理解**，其余原版事务全部落在镜像上，因此一律拒绝并说明。
- **拖拽拒绝而不是复刻**：那要在别人的包上再实现一遍原版的摊分规则。
- **会话用 holder 认，不认标题**（标题可本地化，别的插件也可能用同一个）。
- **每次点击重校验权限**，开着窗被收回的节点会在下一次交互时结束窗口。

完整的推理、事件表与测试手法见 [docs/minimax/18](../docs/minimax/18-invsee.md)。

## 测试

- `InvseeLayoutTest`（7）槽位表：仓储 / 快捷栏不互换、填充格没有索引、双向一致、
  每个护甲槽要求的装备槽。
- `InvseeClickTest`（9）点击真值表与合并数量。
- `InvseeContextTest`（21）MockBukkit 走真实事件：开窗、取物、Shift 直取、护甲（**手上拿着别的东西
  也能取出来**）、给予、守恒恒等式、拖拽拒绝、不支持的点击、权限回收、目标退出、context 关闭、
  tab 补全、对方动背包后窗口自愈、两位管理员同时查看。
- `MeowoRuntimeTest` 覆盖「每条路由的权限都在 plugin.yml 里声明」与根级 `/invsee` 可达。
