# Pomodoro

玩家用 `/meowo pomodoro`（别名 `/pomodoro` / `/pomo`）打开 **水晶柱殿**，选一个预设开始；
插件按「工作 → 短休息 → 重复 N 轮 → 长休息」循环，每秒把倒计时同步到三处读数。

- **BossBar**：状态名、剩余时间、第几轮 / 共几轮，进度条随剩余时间收缩，颜色随状态切换（暂停色覆盖原状态色）。
- **屏幕 Title**：预设名 + 副标题（状态 / 时间 / 轮次）。
- **头顶 TextDisplay**：跟随玩家移动。需要 [PacketEvents](https://modrinth.com/plugin/packetevents) 2.14.0；不在时这一项自动降级，前两项照常。

两个读数（BossBar / Title）是**每个玩家各自**的偏好，用 `/pomodoro visuals bossbar|title on|off` 或柱殿底层的两枚小水晶切换，默认值来自 `pomodoro.bossbar-default` / `pomodoro.title-default`。

## 界面

外观来自 `platform` 的共享 `MenuChrome`——同一套水晶柱也画在 `/meowo menu` 与家园菜单上，规范见 [docs/ui-style.md](../../docs/ui-style.md)。

| 页面 | 形状 |
| --- | --- |
| **柱殿**（`/pomodoro`） | 七根功能柱，柱顶晶体各代表一个功能：开始/继续、暂停、进入休息、结束、预设长廊、新建预设、专注统计；底层两枚小水晶开关读数，另有帮助与关闭 |
| **预设长廊**（`/pomodoro presets`） | 同一套框的列表页：内置在前、自定义在后，一页 28 格；空位是灰色空座位，不是按钮 |
| **编辑器** | 六根字段柱（名称 / 工作 / 短休息 / 长休息 / 轮次 / 图标）加一根「恢复默认」，动作水晶：保存、存为副本、删除；顶部是本预设预览 |
| **确认页** | 两柱，「算了」在左、「确认删除」在右，中间隔开两列；空格用空座位铺满 |

手势：**左键**执行（开始 / 数值 +1 / 改名）、**右键**走另一条路（数值 −1 / 复制 / 编辑），
**Shift+左键**删除。三者都写在 lore 里。不可用的状态不画成灰按钮，而是在 lore 里说清当前状态——
灰按钮仍然长得像按钮，点下去还得解释为什么没反应。

**每页都有出口**：`53` 是关闭（屏障），有上级的页面 `50` 是返回（门）。导航一律不用构成边框的玻璃板，
底行也从玻璃横梁改成**深板岩基座**，这样门/屏障/箭头是那一行唯一显眼的东西。关闭的 lore 会写明
「只关窗口，计时照常继续」——否则玩家会以为关掉就等于结束。

**开关读数会原地重绘页面**：点一下水晶，同一屏里的水晶立刻显示新状态，不会等到下次打开才变。
重绘只替换物品、不重建菜单，TabooLib 已绑定的点击处理器照旧有效。

## 分层与资源

只依赖 `api` / `shared` / `platform`，**不依赖任何其他业务 context**，可单独启停。

| 位置 | 内容 |
| --- | --- |
| `domain/` | `Preset`、`SessionState`、`PomodoroSession`（不可变）、六个 `StateHandler`。纯 Kotlin，无 Bukkit |
| `application/` | `SessionService`（唯一改状态机的地方）、`PresetService`、两个 repository 端口 |
| `infrastructure/` | SQLite 持久化（专用 worker）、`PomodoroVisuals`、`TextDisplayRenderer` |
| `interfaces/` | `PomodoroCommand`、`PomodoroMenuBuilder`（页面形状）、TabooLib GUI 适配器 |

- 数据库：`plugins/Meowo/pomodoro/pomodoro.db`，WAL。
  - `preset`：玩家自定义预设。内置预设**不写库**，每次启动从 jar 内的 `pomodoro-default-presets.yml` 重新读。
  - `focus_log`：每完成一轮工作落一条，`preset_name` 是当时的快照（之后改名不会篡改历史）。
- 自定义预设上限：`pomodoro.custom-preset-limit`（默认 16）。
- 权限：`meowo.pomodoro`（默认所有人）、`meowo.pomodoro.admin`（默认 OP，预留给后续的管理员视图）。

## 状态机

```
WORK ──倒计时归零──▶ WORK_COMPLETED ──next──▶ BREAK ──倒计时归零──▶ WORK
                                    └─最后一轮─▶ LONG_BREAK ──▶ WORK（轮次重置为 1）
任意 ──pause──▶ PAUSED ──resume──▶ 原状态
任意 ──stop──▶ STOPPED
```

`WORK_COMPLETED` 是**等待**状态：这一轮做完了，但由玩家决定何时进入休息——上游 Java 插件也是这么设计的，
它让"再多做五分钟"和"立刻休息"都成立。`extraSeconds` 在这个状态里累加，因此记入统计的是**真实专注时长**
而不是预设时长。副作用（消息、音效、视觉）由 `PomodoroContext` 消费 `SessionService` 返回的事件列表完成，
handler 本身是纯函数，可以脱离服务器测试。

## 自定义预设

编辑器改的是**工作副本**，「保存」才落库，返回等于丢弃。

| 操作 | 手势 |
| --- | --- |
| 改名 | 名称柱左键 → 在聊天栏输入（`cancel` 取消；`§` 与控制字符被拒绝） |
| 工作 / 短休息 / 长休息 | 左键 +1 分钟，右键 −1 分钟，钳在 1 分钟 ~ 3 小时 |
| 轮次 | 左键 +1，右键 −1，范围 1..12 |
| 图标 | 固定材质列表里循环（自由输入材质名玩家拼不出来，拼错只会静默变成时钟） |
| 恢复默认 | 数值回落到内置默认，**名称与图标保留** |
| 存为副本 | 另存一份，命名为 `原名 副本N` 直到不重名 |
| 删除 | 只对已存在的自定义预设；先开确认页，确认才删 |

数值用有界按钮而不是聊天栏输入，是因为越界值只会在很久之后、在已经关掉的界面上被拒——把范围做进按钮，
越界值就不可达。内置预设既不能编辑也不能删除：右键它等于「复制一份再改」。

## 设计取舍

- **不冻结、不拉回玩家。** 上游插件能在工作期间冻结移动、并在越界时把玩家拽回起始点。Meowo 不剥夺玩家的
  移动控制，所以 `pomodoro.max-distance` 只做「越界 → 自动暂停 + 警告」；是否回来、是否继续，由玩家自己决定。
- **头顶文字用非持久化实体。** `TextDisplay` 会被写进区块存档，崩溃或非正常关停会永久留下冻住的计时器，
  而且只有制造它的玩家看不见。因此 `isPersistent = false`——只活在内存里。它也对所有者隐藏，不挡方块交互。
- **漂移判断看事件的目标位置。** `PlayerMoveEvent` / `PlayerTeleportEvent` 携带的是**目的地**，且在玩家抵达之前
  触发；监听器若读 `player.location` 会量到玩家"还在原处"，越界第一步要等下一秒才被发现。
- **只有 `SessionService` 能改状态机。** 每个变更返回**事件列表**而不只是单个事件：离开 `WORK_COMPLETED`
  既要换状态、又要结算一轮专注。早期版本只返回一个事件，逼调用方自行推导第二件事，结果那一轮被每秒重复记一次、
  还记到了错误的轮次上。
- **柱身高度随页面推导，不写死。** 三行确认页放不下「柱头＋柱身＋柱脚」，写死高度会把柱脚写到界面之外——
  那是把一个不存在的槽位交给适配器的装饰性崩溃，现在由一条不变量测试盯住。
- **列表空位是空座位。** 空着像坏了，放按钮像骗人；一个无名字、无动作的灰色格位读作"这里还能放东西"。
- **屏幕标题按固定节奏刷新，不是每秒。** Adventure 围绕 stay 时间做淡入淡出，每秒重发就会每秒
  重播淡入，读数变成一闪一闪。所以新发间隔＝停留时长（`pomodoro.title-refresh-seconds`，默认 5 秒）、
  淡入淡出为 0，阶段/预设/轮次一变立刻重发；每秒精度交给 BossBar。`TitleThrottleTest` 钉住节奏，
  `PomodoroVisualsTest` 通过 `TitleSender` 接缝钉住真实的淡入/停留时长。
- **装饰不得覆盖功能。** 页面分四层合并：柱身 → 空座位 → 功能柱头 → 动作水晶。确认页曾把空座位和
  两根功能柱放进同一层，柱子被盖掉：界面看起来完全正常，却点不动。已有不变量测试。
- **音效配置只列真正会播的项。** 上游还带 `ui-back` / `session-fail`，本移植没有返回导航、也无法中止会话，
  留着就是"配了却没有任何作用"的死开关。
- **重载是干净重来。** `close()` 会丢弃所有会话、视觉、草稿与偏好；重新启用后不会复活旧计时器。
